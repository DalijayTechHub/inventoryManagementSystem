The Suppliers API lets you maintain a directory of the vendors you source products from. Store contact information, preferred currency, and average lead times for each supplier so that Blinks Inventory can surface accurate reorder estimates and auto-populate purchase order fields. Supplier IDs are referenced in the [Purchase Orders API](/api-reference/orders), so create your supplier records before raising POs.

---

## List all suppliers

Retrieve a paginated list of all suppliers in your account. Use the `search` parameter to find a specific supplier by name or email.

```bash
curl -X GET "https://api.blinks.it/v1/suppliers?search=techsource&page=1&per_page=20" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Query parameters

<ParamField query="page" type="integer" default="1">
  The page number to return.
</ParamField>

<ParamField query="per_page" type="integer" default="20">
  Number of suppliers to return per page. Maximum is 100.
</ParamField>

<ParamField query="search" type="string">
  Full-text search across supplier names and email addresses.
</ParamField>

### Response

## Create a supplier

Add a new supplier to your account. Only `name` is required — you can update contact details and lead times at any time.

```bash
curl -X POST "https://api.blinks.it/v1/suppliers" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Pacific Rim Components",
    "email": "procurement@pacificrimco.com",
    "phone": "+1-415-555-0198",
    "address": {
      "line1": "12 Harbor Boulevard",
      "city": "San Francisco",
      "state": "CA",
      "postal_code": "94105",
      "country": "US"
    },
    "lead_time_days": 14,
    "currency": "USD"
  }'
```

### Request body

<ParamField body="name" type="string" required>
  The supplier's display name. Must be unique within your account.
</ParamField>

<ParamField body="email" type="string">
  Primary contact email for this supplier.
</ParamField>

<ParamField body="phone" type="string">
  Contact phone number for this supplier.
</ParamField>

<ParamField body="address" type="object">
  Physical address of the supplier. Accepts `line1`, `line2`, `city`, `state`, `postal_code`, and `country`.
</ParamField>

<ParamField body="lead_time_days" type="integer">
  Average fulfilment lead time in days. Used by Blinks Inventory to calculate recommended reorder dates.
</ParamField>

<ParamField body="currency" type="string">
  ISO 4217 currency code for purchase orders raised with this supplier. Defaults to your account's base currency.
</ParamField>

### Response

Returns the newly created supplier object.

```json
{
  "data": {
    "id": "sup_02B3C4D5E6F7G8H9I0J1K2L3",
    "name": "Pacific Rim Components",
    "email": "procurement@pacificrimco.com",
    "phone": "+1-415-555-0198",
    "address": {
      "line1": "12 Harbor Boulevard",
      "city": "San Francisco",
      "state": "CA",
      "postal_code": "94105",
      "country": "US"
    },
    "lead_time_days": 14,
    "currency": "USD",
    "created_at": "2024-06-10T13:00:00Z"
  }
}
```

## Update a supplier

Update any fields on an existing supplier record. Send only the fields you want to change — all omitted fields remain unchanged.

```bash
curl -X PUT "https://api.blinks.it/v1/suppliers/sup_02B3C4D5E6F7G8H9I0J1K2L3" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "lead_time_days": 10,
    "email": "new-orders@pacificrimco.com"
  }'
```

### Path parameters

<ParamField path="id" type="string" required>
  The unique ID of the supplier to update.
</ParamField>

### Request body

<ParamField body="name" type="string">
  Updated display name for the supplier.
</ParamField>

<ParamField body="email" type="string">
  Updated contact email.
</ParamField>

<ParamField body="phone" type="string">
  Updated contact phone number.
</ParamField>

<ParamField body="address" type="object">
  Updated physical address.
</ParamField>

<ParamField body="lead_time_days" type="integer">
  Updated average lead time in days.
</ParamField>

<ParamField body="currency" type="string">
  Updated ISO 4217 currency code.
</ParamField>

### Response

Returns the full updated supplier object.

## Delete a supplier

Permanently remove a supplier from your account.

<Note>
  Deleting a supplier does **not** delete any purchase orders that were created for that supplier. Existing purchase orders retain their supplier details as a snapshot and remain fully accessible. However, you will no longer be able to create new purchase orders against a deleted supplier.
</Note>

```bash
curl -X DELETE "https://api.blinks.it/v1/suppliers/sup_02B3C4D5E6F7G8H9I0J1K2L3" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Path parameters

<ParamField path="id" type="string" required>
  The unique ID of the supplier to delete.
</ParamField>

### Response

Returns `204 No Content` on success with an empty body.
