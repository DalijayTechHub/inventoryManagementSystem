The Warehouses API lets you model every physical location in your fulfilment network. Create warehouses for each storage site, assign a default location for new inventory, and retrieve the zones and bin locations configured within each building. Warehouse IDs are referenced by the Inventory and Orders APIs, so set up your warehouses before creating stock records or purchase orders.

---

## List all warehouses

Retrieve a paginated list of all warehouses in your account.

```bash
curl -X GET "https://api.blinks.it/v1/warehouses?page=1&per_page=20" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Query parameters

<ParamField query="page" type="integer" default="1">
  The page number to return.
</ParamField>

<ParamField query="per_page" type="integer" default="20">
  Number of warehouses to return per page. Maximum is 100.
</ParamField>

## Create a warehouse

Add a new warehouse to your account. Only `name` is required — you can add address details and configure zones later.

```bash
curl -X POST "https://api.blinks.it/v1/warehouses" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Midwest Distribution Center",
    "address": {
      "line1": "200 Industrial Pkwy",
      "city": "Chicago",
      "state": "IL",
      "postal_code": "60601",
      "country": "US"
    },
    "timezone": "America/Chicago",
    "is_default": false
  }'
```

### Request body

<ParamField body="name" type="string" required>
  The display name for the warehouse. Must be unique within your account.
</ParamField>

<ParamField body="address" type="object">
  Physical address of the warehouse. Accepts `line1`, `line2`, `city`, `state`, `postal_code`, and `country`.
</ParamField>

<ParamField body="timezone" type="string">
  IANA timezone string for the warehouse (e.g. `America/Chicago`). Defaults to your account's base timezone.
</ParamField>

<ParamField body="is_default" type="boolean">
  Set to `true` to make this the default warehouse. Only one warehouse can be the default at a time — setting this to `true` will unset any existing default.
</ParamField>

### Response

Returns the newly created warehouse object.

```json
{
  "data": {
    "id": "wh_03C4D5E6F7G8H9I0J1K2L3M4",
    "name": "Midwest Distribution Center",
    "address": {
      "line1": "200 Industrial Pkwy",
      "city": "Chicago",
      "state": "IL",
      "postal_code": "60601",
      "country": "US"
    },
    "timezone": "America/Chicago",
    "is_default": false,
    "created_at": "2024-05-20T16:45:00Z"
  }
}
```

## Get a warehouse

Retrieve the full details of a single warehouse by its ID, including its configured zones.

```bash

  -H "Authorization: Bearer YOUR_API_KEY"
```

## Update a warehouse

Update the name, address, timezone, or default status of an existing warehouse. Send only the fields you want to change.

```bash
curl -X PUT "https://api.blinks.it/v1/warehouses/wh_03C4D5E6F7G8H9I0J1K2L3M4" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Midwest Distribution Center — Chicago",
    "is_default": true
  }'
```

### Path parameters

<ParamField path="id" type="string" required>
  The unique ID of the warehouse to update.
</ParamField>

### Request body

<ParamField body="name" type="string">
  Updated display name for the warehouse.
</ParamField>

<ParamField body="address" type="object">
  Updated physical address. Accepts the same fields as on create.
</ParamField>

<ParamField body="timezone" type="string">
  Updated IANA timezone string.
</ParamField>

<ParamField body="is_default" type="boolean">
  Set to `true` to make this warehouse the new default.
</ParamField>

### Response

Returns the full updated warehouse object.

```json
{
  "data": {
    "id": "wh_03C4D5E6F7G8H9I0J1K2L3M4",
    "name": "Midwest Distribution Center — Chicago",
    "address": {
      "line1": "200 Industrial Pkwy",
      "city": "Chicago",
      "state": "IL",
      "postal_code": "60601",
      "country": "US"
    },
    "timezone": "America/Chicago",
    "is_default": true,
    "created_at": "2024-05-20T16:45:00Z"
  }
}
```

## Delete a warehouse

Permanently remove a warehouse from your account.

<Note>
  You cannot delete a warehouse that currently holds any inventory. Use the [Inventory Adjustments API](/api-reference/inventory#adjust-stock-quantity) to move or zero out all stock in the warehouse first, then retry the delete.
</Note>

```bash
curl -X DELETE "https://api.blinks.it/v1/warehouses/wh_03C4D5E6F7G8H9I0J1K2L3M4" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Path parameters

<ParamField path="id" type="string" required>
  The unique ID of the warehouse to delete.
</ParamField>

### Response

Returns `204 No Content` on success with an empty body.
