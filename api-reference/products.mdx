The Products API gives you full control over your product catalog. Use it to create new SKUs, update pricing and reorder thresholds, retrieve detailed product records including variant breakdowns, and remove products that are no longer needed. All requests must include your API key in the `Authorization` header, and all responses are returned as JSON.

---

## List all products

Retrieve a paginated list of products in your catalog. Use the query parameters to filter by category, search by name or SKU, and control sort order.

```bash
curl -X GET "https://api.blinks.it/v1/products?page=1&per_page=25&sort=name" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Query parameters

<ParamField query="page" type="integer" default="1">
  The page number to return.
</ParamField>

<ParamField query="per_page" type="integer" default="20">
  The number of products to return per page. Maximum is 100.
</ParamField>

<ParamField query="category" type="string">
  Filter products by category name. Returns only products assigned to the specified category.
</ParamField>

<ParamField query="search" type="string">
  Full-text search across product names and SKUs.
</ParamField>

<ParamField query="sort" type="string" default="created_at">
  Sort order for results. Accepted values: `name`, `created_at`.
</ParamField>

## Create a product

Add a new product to your catalog. The `name` and `sku` fields are required; all other fields are optional and can be updated later.

```bash
curl -X POST "https://api.blinks.it/v1/products" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Mechanical Gaming Mouse",
    "sku": "MGM-RGB-001",
    "barcode": "112233445566",
    "category": "Electronics",
    "cost_price": 18.00,
    "selling_price": 44.99,
    "reorder_point": 40,
    "description": "High-DPI mechanical gaming mouse with RGB lighting."
  }'
```

### Request body

<ParamField body="name" type="string" required>
  The product's display name. Must be unique within your account.
</ParamField>

<ParamField body="sku" type="string" required>
  Your internal Stock Keeping Unit code. Must be unique within your account.
</ParamField>

<ParamField body="barcode" type="string">
  Barcode value for the product (UPC, EAN, or custom format).
</ParamField>

<ParamField body="category" type="string">
  Category name to assign the product to.
</ParamField>

<ParamField body="cost_price" type="number">
  Your purchase cost for the product.
</ParamField>

<ParamField body="selling_price" type="number">
  The price at which you sell the product.
</ParamField>

<ParamField body="reorder_point" type="integer">
  The stock threshold that triggers a low-stock alert.
</ParamField>

<ParamField body="description" type="string">
  A free-text description of the product.
</ParamField>

### Response

Returns the newly created product object with its assigned `id`.

```json
{
  "data": {
    "id": "prod_03K0Z4M1O5P6Q7R8S9T0U1V2W3",
    "name": "Mechanical Gaming Mouse",
    "sku": "MGM-RGB-001",
    "barcode": "112233445566",
    "category": "Electronics",
    "cost_price": 18.00,
    "selling_price": 44.99,
    "reorder_point": 40,
    "description": "High-DPI mechanical gaming mouse with RGB lighting.",
    "created_at": "2024-04-01T14:22:00Z"
  }
}
```

```bash

  -H "Authorization: Bearer YOUR_API_KEY"
```

## Update a product

Update any fields on an existing product. Send only the fields you want to change — omitted fields remain unchanged.

```bash
curl -X PUT "https://api.blinks.it/v1/products/prod_03K0Z4M1O5P6Q7R8S9T0U1V2W3" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "selling_price": 49.99,
    "reorder_point": 60
  }'
```

### Path parameters

<ParamField path="id" type="string" required>
  The unique ID of the product to update.
</ParamField>

### Request body

<ParamField body="name" type="string">
  Updated display name for the product.
</ParamField>

<ParamField body="sku" type="string">
  Updated SKU. Must remain unique within your account.
</ParamField>

<ParamField body="barcode" type="string">
  Updated barcode value.
</ParamField>

<ParamField body="category" type="string">
  Updated category assignment.
</ParamField>

<ParamField body="cost_price" type="number">
  Updated purchase cost.
</ParamField>

<ParamField body="selling_price" type="number">
  Updated selling price.
</ParamField>

<ParamField body="reorder_point" type="integer">
  Updated low-stock alert threshold.
</ParamField>

<ParamField body="description" type="string">
  Updated free-text description.
</ParamField>

### Response

Returns the full updated product object.

```json
{
  "data": {
    "id": "prod_03K0Z4M1O5P6Q7R8S9T0U1V2W3",
    "name": "Mechanical Gaming Mouse",
```

## Delete a product

Permanently remove a product from your catalog. This action cannot be undone.

<Note>
  You cannot delete a product that currently has inventory on hand in any warehouse. First reduce the product's stock to zero via the [Inventory Adjustments API](/api-reference/inventory#adjust-stock-quantity), then retry the delete.
</Note>

```bash
curl -X DELETE "https://api.blinks.it/v1/products/prod_03K0Z4M1O5P6Q7R8S9T0U1V2W3" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Path parameters

<ParamField path="id" type="string" required>
  The unique ID of the product to delete.
</ParamField>

### Response

Returns `204 No Content` on success with an empty response body.

<Tip>
  If you want to hide a product from active use without deleting it, consider updating its `category` to an archived category rather than deleting it outright.
</Tip>
